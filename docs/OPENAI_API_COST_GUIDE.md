# TalkOn OpenAI API料金ガイド

## 1. この資料の目的

TalkOnの英会話で、どの処理にOpenAI API料金が発生するかを整理します。

また、毎日15分利用した場合に、月額1,500円以内で運用できるかを概算します。

料金は2026年8月16日時点の公開情報を基準にしています。OpenAIの料金改定、為替、実際の会話量によって変わるため、最終的な請求額はOpenAI PlatformのUsage画面で確認します。

## 2. TalkOnで料金が発生する処理

TalkOnでは、主に次の処理でAPI料金が発生します。

| 処理                       | 使用モデル               | 課金対象                               |
| -------------------------- | ------------------------ | -------------------------------------- |
| 会話開始時の挨拶           | `gpt-5.6-luna`           | 入力・出力テキストトークン             |
| 会話への返答               | `gpt-5.6-luna`           | 入力・出力テキストトークン             |
| 日本語翻訳                 | `gpt-5.6-luna`           | 入力・出力テキストトークン             |
| 会話終了後のフィードバック | `gpt-5.6-luna`           | 入力・出力テキストトークン             |
| ユーザー音声の文字起こし   | `gpt-4o-mini-transcribe` | 入力音声トークン・出力テキストトークン |
| AI英文の読み上げ           | `gpt-4o-mini-tts`        | 入力テキストトークン・出力音声トークン |

文字入力だけで会話し、AI英文の読み上げも利用しない場合は、音声認識と音声合成の料金は発生しません。

## 3. 現在の主な単価

### 3.1 GPT-5.6 Luna

| 種類               | 100万トークンあたり |
| ------------------ | ------------------: |
| 入力               |            1.00ドル |
| キャッシュ済み入力 |            0.10ドル |
| 出力               |            6.00ドル |

公式情報: [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)

### 3.2 GPT-4o mini Transcribe

| 種類         | 100万トークンあたり |
| ------------ | ------------------: |
| 入力音声     |            1.25ドル |
| 出力テキスト |            5.00ドル |

公式情報: [GPT-4o mini Transcribe](https://developers.openai.com/api/docs/models/gpt-4o-mini-transcribe)

音声の内容や変換結果によって変動しますが、予算計算では1分あたり約0.003ドルを目安として使用します。

### 3.3 GPT-4o mini TTS

| 種類         | 100万トークンあたり |
| ------------ | ------------------: |
| 入力テキスト |            0.60ドル |
| 出力音声     |           12.00ドル |

公式情報: [GPT-4o mini TTS](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts)

音声の長さや読み上げ速度によって変動しますが、予算計算では出力音声1分あたり約0.015ドルを目安として使用します。

このモデルは公式ページでDeprecatedと表示されているため、廃止予定が明確になった場合は後継モデルへの変更と料金の再計算が必要です。

## 4. トークンとは何か

トークンは、AIが文章を処理するために分割した文字列の単位です。

入力トークンには、ユーザーが入力した英文だけでなく、次の内容も含まれます。

- TalkOnから渡す会話ルール
- 英語レベルに応じた指示
- 過去の会話履歴
- 翻訳やフィードバック生成の指示

出力トークンは、AIが生成した英文、翻訳、フィードバックなどです。

会話が長くなると、過去の履歴を再送する量が増えるため、1回の返答に必要な入力トークンも増えます。TalkOnでは送信する履歴数に上限を設定し、際限なく増えないようにしています。

## 5. TalkOnがトークン数を取得する仕組み

Chat Completions APIのレスポンスには、次のような`usage`情報が含まれます。

```json
{
  "usage": {
    "prompt_tokens": 1122,
    "completion_tokens": 110,
    "total_tokens": 1232
  }
}
```

TalkOnでは、`prompt_tokens`を入力トークン、`completion_tokens`を出力トークンとして保存します。

主な実装場所は次のとおりです。

- `backend/src/main/java/com/kazuto/talkon/llm/AiClientConfig.java`
- `backend/src/main/java/com/kazuto/talkon/conversation/ConversationService.java`
- `backend/src/main/java/com/kazuto/talkon/conversation/LlmCostCalculator.java`
- `backend/src/main/java/com/kazuto/talkon/conversation/ConversationSession.java`
- `frontend/src/App.tsx`
- `frontend/src/features/conversation/FeedbackPanel.tsx`

## 6. 画面に表示される概算料金

TalkOnの会話画面に表示されるトークン数と料金は、現時点では次の処理だけを集計しています。

- 会話開始時のAI挨拶
- 会話中のAI返答

次の処理は画面の概算料金に含まれていません。

- 日本語翻訳
- 会話終了後のフィードバック生成
- 音声認識
- 音声合成

したがって、TalkOnの表示金額はOpenAIから請求される総額ではありません。アプリ内では会話本文の増え方を確認し、請求全体はOpenAI PlatformのUsage画面で確認します。

## 7. 料金の計算式

### 7.1 Lunaの文章生成

```text
ドル料金
= 入力トークン数 × 入力単価 ÷ 1,000,000
+ 出力トークン数 × 出力単価 ÷ 1,000,000

円料金
= ドル料金 × 1ドルあたりの円換算値
```

入力1,122トークン、出力110トークン、1ドル160円の場合は次の計算になります。

```text
入力料金 = 1,122 × 1.00ドル ÷ 1,000,000 = 0.001122ドル
出力料金 = 110 × 6.00ドル ÷ 1,000,000 = 0.000660ドル
合計     = 0.001782ドル
円換算   = 0.001782ドル × 160円 = 約0.285円
```

### 7.2 音声認識と音声合成

月額の簡易見積もりでは、次の式を使用します。

```text
音声認識 = ユーザーが話した分数 × 0.003ドル × 160円
音声合成 = AIが話した分数 × 0.015ドル × 160円
```

これは予算を立てるための概算です。実際の請求は音声トークン数で決まります。

## 8. 毎日15分利用する場合の月額目安

### 8.1 前提

- 1日15分利用する
- 1か月を30日とする
- ユーザーとAIが半分ずつ話す
- ユーザーの音声は1日7.5分とする
- AIの音声は1日7.5分とする
- 1ドル160円で計算する
- 翻訳とフィードバックを毎日利用する

### 8.2 音声部分

```text
音声認識
= 7.5分 × 30日 × 0.003ドル × 160円
= 約108円

音声合成
= 7.5分 × 30日 × 0.015ドル × 160円
= 約540円

音声部分の合計
= 約648円
```

### 8.3 文章生成を含めた全体

Lunaによる会話、翻訳、フィードバックは会話量によって変動します。毎日15分の利用では、文章生成部分を月100円から300円程度の予備枠として見積もります。

| 項目                       |       月額目安 |
| -------------------------- | -------------: |
| 音声認識                   |        約108円 |
| 音声合成                   |        約540円 |
| 会話・翻訳・フィードバック | 約100円〜300円 |
| 合計                       | 約750円〜950円 |

余裕を含めた運用予算としては、月1,000円から1,200円程度を見ておくと安全です。

通常の利用であれば、毎日15分でも月1,500円以内を目指せます。ただし、AI音声の再生成や長時間利用が多い場合は超える可能性があります。

## 9. 利用時間別の目安

ユーザーとAIが半分ずつ話す前提での概算です。

| 1日の利用時間 | 音声部分の月額 |     全体の月額目安 |
| ------------: | -------------: | -----------------: |
|           5分 |        約216円 |     約300円〜450円 |
|          15分 |        約648円 |     約750円〜950円 |
|          30分 |      約1,296円 | 約1,500円〜1,900円 |

30分以上を毎日利用する場合は、月1,500円を超える可能性が高くなります。

## 10. 月1,500円以内に抑える方法

- OpenAI Platformで月次の利用上限を設定する
- 最初は自動チャージをOFFにする
- Usage画面を週に1回確認する
- 会話履歴として送信する件数に上限を設ける
- 同じAI音声を再生するときは、生成済み音声を再利用する
- 翻訳済みの文章を再度APIへ送らず、保存した翻訳を表示する
- フィードバックの再生成回数を制限する
- 料金表示に音声・翻訳・フィードバックも追加する

## 11. 現在の設定で注意すること

TalkOnの`.env`では、概算料金用のLuna単価を次の値にする必要があります。

```env
LLM_INPUT_USD_PER_MILLION=1.00
LLM_OUTPUT_USD_PER_MILLION=6.00
LLM_YEN_PER_USD=160
```

以前設定していた入力0.20ドル、出力1.20ドルのままでは、画面の概算料金が現在の公式単価より5分の1程度に表示されます。

この設定は画面表示の計算に使う値であり、OpenAI側の実際の請求単価を変更するものではありません。

## 12. 正確な請求額の確認場所

最終的な請求額は、OpenAI PlatformのUsage画面で確認します。

- Usage: <https://platform.openai.com/usage>
- Billing: <https://platform.openai.com/settings/organization/billing/overview>

TalkOn側の表示は機能ごとの目安、OpenAI Platform側の表示は実際の利用量と考えます。

## 13. 料金を見直すタイミング

次の場合は、この資料と`.env`の単価を更新します。

- OpenAIがモデル料金を変更したとき
- 使用モデルを変更したとき
- 為替の前提を変更したとき
- TTSの後継モデルへ移行したとき
- TalkOnがRealtime APIを採用したとき
- 音声や翻訳をアプリ内料金表示へ追加したとき
